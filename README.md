# קינון — מתכוננים ללידה, ביחד

אפליקציה משותפת לזוג שמתכונן ללידה: **משימות, ציוד, תיק לידה, טיימר צירים וקישורים חשובים** —
מהשבועות האחרונים של ההריון, דרך חדר הלידה ועד החודשים הראשונים בבית.
שניכם נכנסים עם חשבון Google, וכל סימון של אחד מכם מופיע מיד אצל השני.
האפליקציה **פרטית**: רק החשבונות שברשימת המורשים (`src/lib/access.ts` + `firestore.rules`) יכולים להיכנס.

> **Kinun** (Hebrew for "nesting") — a shared, real-time birth-preparation app for a couple in Israel.
> Installable PWA for iPhone and Android · React + TypeScript + Firebase. Coding agents: start at [AGENTS.md](AGENTS.md).

## מה יש בפנים

- **בית** — כרטיס שבוע ההריון עם טבעת התקדמות, מה צריך לעשות עכשיו, איפה אתם עומדים, ומה השתנה לאחרונה (ומי שינה).
- **משימות** — כ-70 משימות לפי שלבים: במהלך ההריון, לקראת הלידה, בלידה, בבית החולים, בשבועות ובחודשים הראשונים.
  כל משימה מתוזמנת לפי שבוע ההריון או לפי ימים אחרי הלידה, ואפשר לשייך אותה לאחד מכם או לשניכם.
- **ציוד** — כ-50 פריטים לתינוק, לבית וליולדת, עם עדיפות (חובה / מומלץ / אופציונלי) וסטטוס (צריך / בדרך / יש / לא צריך).
- **תיק לידה** — רשימת אריזה: מסמכים, ליולדת, לתינוק ולמלווה.
- **מצב לידה** — טיימר צירים משותף לשני הטלפונים, סיכום של השעה האחרונה, חיוג וניווט לבית החולים בלחיצה, ו"מתי נוסעים".
- **קישורים וטלפונים** — ביטוח לאומי, כל זכות, רישום התינוק, טיפות חלב, בתי חולים באזור המרכז, בטרם, קווים חמים.
- **הכול ניתן לעריכה** — להוסיף, לשנות, למחוק, להעביר בין שלבים, להוסיף קישורים לכל פריט.

התוכן נבנה ממחקר על מקורות רשמיים (ביטוח לאומי, gov.il, כל זכות, קופות החולים, בתי החולים, בטרם) ונבדק ב-21.11.2026.
לכל פריט שמבוסס על עובדה יש קישור למקור. פירוט: [docs/RESEARCH.md](docs/RESEARCH.md).

## להתחיל

### לנסות מיד (בלי שום הגדרה)

```bash
npm ci
npm run dev:demo
```

במצב הדגמה הנתונים נשמרים רק בדפדפן הזה. זה טוב לראות איך זה נראה, לא לסנכרון בין שני טלפונים.

### האפליקציה שלנו

**<https://kinun-ae894.web.app>** — פותחים בטלפון, מוסיפים למסך הבית ונכנסים עם Google.

ההקמה ב-Firebase (בחינם), העלאת גרסה חדשה והקמה מחדש בפרויקט אחר: [docs/SETUP-FIREBASE.md](docs/SETUP-FIREBASE.md).

### התקנה בטלפון

- **אייפון:** פותחים את הכתובת ב-Safari ← כפתור השיתוף ← **הוספה למסך הבית**. נכנסים עם Google מתוך האפליקציה שהותקנה.
- **אנדרואיד:** פותחים ב-Chrome ← תפריט ⋮ ← **התקנת אפליקציה**.

### להוסיף את בן/בת הזוג

בהגדרות ← "מי משתמש באפליקציה" ← "הוספת …" ליד החשבון המורשה ← "שליחת קישור לאפליקציה".
ברגע שהם נכנסים עם אותו חשבון Google, הרשימות שלכם מופיעות אצלם.
אפשר להוסיף רק חשבונות מרשימת המורשים. כדי לאשר חשבון חדש מעדכנים את הרשימה **בשני המקומות** —
`src/lib/access.ts` ו-`allowlist()` ב-`firestore.rules` (בדיקה אוטומטית מוודאת שהם זהים) — ופורסים מחדש גם את החוקים.

## פיתוח

| פקודה                              | מה היא עושה                                           |
| ---------------------------------- | ----------------------------------------------------- |
| `npm run dev:demo`                 | שרת פיתוח במצב הדגמה (בלי Firebase)                   |
| `npm run dev`                      | שרת פיתוח מול Firebase (צריך `.env.local`)            |
| `npm run check`                    | בדיקת טיפוסים, lint ובדיקות יחידה                     |
| `npm run test:e2e`                 | בדיקת קצה-לקצה בגודל טלפון (Playwright)               |
| `npm run test:rules`               | בדיקות לחוקי האבטחה של Firestore (דורש Java; רץ ב-CI) |
| `npm run check:links`              | בדיקה שכל הקישורים בתוכן עדיין עובדים                 |
| `npm run build` / `npm run deploy` | בנייה / פריסה ל-Firebase Hosting                      |
